NCVoters Duplicate Detection

Fragmented-ID-Resolution for Voter Registration Records

This app uses deep-learning and baseline matching models to detect likely duplicate voter-registration records. It can scan an entire database for duplicate risk or help a clerk check whether one new incoming registration already exists.

  1. Load a voter-registration dataset by path or file upload.
  2. Choose the model you want to use for scoring.
  3. Either run a full duplicate scan or check one new entry.
  4. Review the ranked results, duplicate summary, and cluster profiles.
